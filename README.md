# PeopleMesh

PeopleMesh is a focused people directory for finding people and understanding where they fit.

This repository currently contains the application foundation. Directory and profile experiences are not implemented yet.

## Technologies

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- npm

## Local setup

Use a current Node.js LTS release (Node 22 or 24). Then:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```
